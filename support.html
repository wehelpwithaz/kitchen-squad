Aide

Questions fréquentes et contact.

Comment jouer ?

Déplace ton chef avec le joystick à gauche. Le bouton main prend, pose et coupe ; le bouton course fait un sprint ; le bouton rond change de chef. Suis les tickets à gauche : ils montrent le plat fini et ses étapes.

Comment fonctionnent les cœurs ?

Les niveaux 1 à 3 sont gratuits. Ensuite, chaque partie coûte 1 cœur, rendu si tu fais 3 étoiles. Un cœur revient tout seul toutes les 30 minutes, et une vidéo au choix peut en rendre.

Comment débloquer les autres chefs ?

Theo, Yuki et Lina se débloquent en avançant dans l'aventure, puis s'achètent avec les pièces gagnées en jouant. Rien ne s'achète avec de l'argent réel.

Comment améliorer mes chefs ?

Joue avec un chef pour lui faire gagner de l'expérience. À chaque niveau, il reçoit 5 points à placer dans « Compétences ». Avant de valider, « − » rend le point gratuitement ; après, la réinitialisation coûte 300 pièces.

Comment sauvegarder ma partie ?

Accueil > Mode Histoire > « Sauvegarder : copier mon code ». Garde ce code dans tes notes ou un e-mail. Après une réinstallation, colle-le dans « Charger une partie ».

Je ne vois pas de vidéo avec récompense

Les vidéos ne s'affichent que si une annonce est disponible et si ta connexion internet fonctionne. Réessaie un peu plus tard.

Comment supprimer mes données ?

Paramètres Android > Applications > Kitchen Squad > Stockage > Effacer les données, ou désinstalle le jeu. Plus de détails dans la page Confidentialité.
